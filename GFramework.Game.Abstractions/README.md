# Game.Abstractions

[简体中文](#简体中文) · [English](#english)

## 简体中文

为共享游戏项目提供内容、输入、存档、场景、UI 和宿主接口。通过 Game 或对应引擎适配提供实现。

[查看使用说明](https://gewuyou.github.io/GFramework/zh-CN/abstractions/game-abstractions.html)

## English

Share content, input, save, scene, UI, and host interfaces across game projects. Supply implementations from Game or the relevant engine integration.

[Read the guide](https://gewuyou.github.io/GFramework/abstractions/game-abstractions.html)

## 安装 · Install

```bash
dotnet add package GeWuYou.GFramework.Game.Abstractions
```
