# 实施路线图

路线图记录实施顺序与每项任务的唯一当前状态，不替代源码契约或架构决策。

- [核心治理](core-governance.md)：文档交付、第一批基础语义修正和后续采用边界。
- [保留的后续事项](retained-followups.md)：从旧主题筛选的其他候选工作。

## 状态与维护

状态使用 planned、in_progress、blocked、done、deferred。done 必须有适用于当前改动的验证证据；blocked 写明具体阻塞条件；deferred 说明重新启动条件。

每个任务维护目标、边界、验收、证据和下一步。证据过期或代码已改变时重新核对，不把旧勾选和历史 CI 直接带入当前任务。详细过程交给 Git，不再为每轮执行新增追踪文件。

当前顺序：完成文档治理 → 统一 DI/资源/实例隔离 → 独立采用边界与调用收敛。其他增强只由真实使用需求触发。
