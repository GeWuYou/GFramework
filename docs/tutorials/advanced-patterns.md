# Extend an existing game {#overview}

Identify the use case you want to extend. Use [CQRS pipelines](../core/cqrs.md) for common request behavior and [shared state](../core/state-management.md) for immutable snapshots used by several views. For user-supplied content and assets, expose a [content pack](../game/content-packs.md) entry point and design stable IDs for saves.
