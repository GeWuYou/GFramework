# 组织项目依赖 {#overview}

| 层次 | 示例职责 |
| --- | --- |
| 领域 | 回合状态、计分和约束 |
| 应用 | 开局、继续、保存与退出 |
| 宿主适配 | 场景树、文件与渲染 |
| 组合根 | 构造依赖、注册服务、启动和停止 |

把依赖通过构造函数交给用例，为实际的宿主边界定义接口。增加新功能时，在相关功能目录实现规则和适配。可运行目录结构见[进阶 Godot 项目](../tutorials/godot-advanced-project.md)。
