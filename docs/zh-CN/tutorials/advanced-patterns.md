# 进阶开发范式

推荐采用标准 DI、按功能组织的轻量分层与可选生命周期编排。进阶能力应服务具体用例，并在完整应用中保持清晰依赖。

- 领域对象维护状态和规则，应用服务组织开始、保存、恢复及结束等用例。
- 基础设施实现存储、内容和宿主端口，组合根显式装配。
- 本地事件用于同步事实通知；异步请求处理管线按需采用 CQRS。
- 生命周期显式登记，业务停止与资源所有权分别处理。
- 状态机管理离散状态切换，帧循环由游戏宿主驱动。
- Mod 在明确的内容、行为及存档接口上扩展，权限与错误边界保持可观察。

从现有游戏到完整分层示例的实践见 [DodgeTheCreeps 进阶教程](./godot-advanced-project.md)。
