# Godot 扩展方法 {#overview}

| 任务 | 入口 |
| --- | --- |
| 识别 `res://` 或 `user://` 路径 | `GodotPathExtensions` |
| 在节点上执行常见操作 | `NodeExtensions` |
| 设置原生信号连接 | [SignalFluentExtensions](../godot/signal.md) |
| 让订阅跟随节点寿命 | `SubscriptionExtensions` |

字段注入和固定信号绑定见[Godot 源码生成器](../source-generators/index.md)。
