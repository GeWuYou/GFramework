# Godot 集成 {#overview}

使用匹配的 Godot .NET 编辑器和 `GeWuYou.GFramework.Godot`。初次接入先运行[最小 Godot 场景](../tutorials/godot-integration.md)，再按任务配置原生适配。

| 任务 | 指南 |
| --- | --- |
| 启动与释放节点服务 | [宿主装配](../godot/architecture.md) |
| 显示场景、页面和对话框 | [场景路由](../godot/scene.md) · [原生 UI](../godot/ui.md) |
| 处理输入、信号与暂停 | [InputMap](../godot/input.md) · [信号](../godot/signal.md) · [暂停](../godot/pause.md) |
| 推进帧流程及复用节点 | [协程](../godot/coroutine.md) · [节点池](../godot/pool.md) |
| 读写资源与用户数据 | [资源](../godot/resource.md) · [存储](../godot/storage.md) · [设置](../godot/setting.md) |

完整运行流程见[Godot 运行示例](../godot/runtime-sample.md)。
