# 贡献指南 {#overview}

1. 从 GitHub 检出代码，按照[开发环境](./contributor/development-environment.md)准备工具。
2. 运行受影响项目的构建和测试。改变采用方式时，同步更新两种语言页面和示例。
3. 使用 Conventional Commits 描述变更。在 PR 中记录用户影响、相关 issue 和已执行的验证。

仓库工作流、命名和打包细节见[贡献规则](https://github.com/GeWuYou/GFramework/blob/main/AGENTS.md)与[开发文档](https://github.com/GeWuYou/GFramework/tree/main/engineering)。
