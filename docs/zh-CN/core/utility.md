# 通用工具 {#overview}

把无状态计算写成普通函数。将时钟、存储和加载器作为构造参数传入需要访问资源的服务。

| 用途 | 入口 |
| --- | --- |
| 数量与紧凑格式 | `NumericDisplayFormatter` 与[数值扩展](../core/extensions.md) |
| 文本表与动态格式 | [本地化](../core/localization.md) |
| 表达缺席或失败 | [Option 与 Result](../core/functional.md) |
| 复用对象或资源 | [对象池](../core/pool.md) · [资源租约](../core/resource.md) |
