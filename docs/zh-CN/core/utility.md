# 通用能力

无状态计算可写为静态函数。包含资源、配置或外部访问的通用能力使用普通服务，通过构造函数接收依赖。

接口用于描述需要隔离的能力，例如时钟、存储或资源加载器。注册时采用标准 DI，不需要 Utility 标记或上下文基类。独立工具可以直接构造。

现有可采用能力包括 [资源管理](./resource.md)、[本地化](./localization.md)、[对象池](./pool.md) 和 [函数式辅助](./functional.md)。数值显示使用 NumericDisplayFormatter 等明确入口，具体行为以其 XML 契约为准。
