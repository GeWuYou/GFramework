# 依赖边界

业务依赖通过构造函数声明。方法只在执行某一次操作时需要的值通过参数传递。

Architecture.Services 用于宿主装配，不传入领域对象和应用服务。业务对象无需保存架构、容器或通用服务上下文。这样可以从构造函数看出依赖，并在普通 C# 测试中直接构造对象。

Godot 场景节点由引擎创建时，由拥有它的场景或组合根显式调用初始化方法，传入具体动作接口、视图状态和日志。场景间的通信由共同拥有者装配；节点独立维护自身展示和交互。

[领域模型](./model.md)、[应用服务](./system.md) 与 [装配入口](./architecture.md) 分别说明这几种职责。
