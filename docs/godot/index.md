# Godot integration {#overview}

Use the matching Godot .NET editor and `GeWuYou.GFramework.Godot`. Start by running the [minimal Godot scene](../tutorials/godot-integration.md), then configure native adapters by task.

| Task | Guide |
| --- | --- |
| Start and release node services | [Host composition](../godot/architecture.md) |
| Show scenes, pages, and dialogs | [Scene routing](../godot/scene.md) and [native UI](../godot/ui.md) |
| Handle input, signals, and pause | [InputMap](../godot/input.md), [signals](../godot/signal.md), and [pause](../godot/pause.md) |
| Run frame flows and reuse nodes | [Coroutines](../godot/coroutine.md) and [node pools](../godot/pool.md) |
| Read resources and write user data | [Resources](../godot/resource.md), [storage](../godot/storage.md), and [settings](../godot/setting.md) |

See the [Godot runtime sample](../godot/runtime-sample.md) for a complete game flow.
