# Godot extensions {#overview}

| Task | Entry point |
| --- | --- |
| Recognize `res://` or `user://` paths | `GodotPathExtensions` |
| Perform common node operations | `NodeExtensions` |
| Configure native signal connections | [SignalFluentExtensions](../godot/signal.md) |
| Tie subscriptions to node lifetime | `SubscriptionExtensions` |

See [Godot source generators](../source-generators/index.md) for field injection and static signal bindings.
