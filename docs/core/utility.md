# Utilities {#overview}

Write stateless calculations as ordinary functions. Pass clocks, storage, and loaders through constructors to services that access resources.

| Need | Entry point |
| --- | --- |
| Number and compact formatting | `NumericDisplayFormatter` and [numeric extensions](../core/extensions.md) |
| Text tables and dynamic formatting | [Localization](../core/localization.md) |
| Represent missing values or failures | [Option and Result](../core/functional.md) |
| Reuse objects or resources | [Object pools](../core/pool.md) and [resource leases](../core/resource.md) |
