# Core {#overview}

Add foundational utilities with `GeWuYou.GFramework.Core`. Register dependencies in the host's composition root and add lifecycle coordination as needed.

| Task | Guide |
| --- | --- |
| Start, stop, and release services | [Compose an application](../core/architecture.md) |
| Notify components about state changes | [Publish synchronous events](../core/events.md) |
| Bind a view to state | [Observe a property](../core/property.md) · [Manage shared state](../core/state-management.md) |
| Advance a game flow | [Coroutines](../core/coroutine.md) · [State machines](../core/state-machine.md) |
| Manage resource and object lifetimes | [Resource leases](../core/resource.md) · [Object pools](../core/pool.md) |
| Handle requests and notifications | [CQRS runtime](../core/cqrs.md) |
