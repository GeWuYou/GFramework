# Contributing {#overview}

1. Check out the repository from GitHub and prepare the tools in [development environment](./contributor/development-environment.md).
2. Build and test affected projects. If an adoption path changes, update both language versions and the example.
3. Use Conventional Commits. Describe user impact, related issues, and validation in the pull request.

See the [repository rules](https://github.com/GeWuYou/GFramework/blob/main/AGENTS.md) and [contributor documentation](https://github.com/GeWuYou/GFramework/tree/main/engineering) for workflow, naming, and packaging.
