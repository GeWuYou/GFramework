# Verify mobile behavior {#overview}

Start with the target devices and native host your game supports. Measure frame time, memory, startup, and thermal behavior. Background and resume the app and check input, pause state, and load failures. Put platform integration in the host and verify that common operations and saves can recover.

See [measure game performance](../best-practices/performance.md).
