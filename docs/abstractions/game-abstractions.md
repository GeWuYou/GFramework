# Game contracts {#overview}

Use `GeWuYou.GFramework.Game.Abstractions` to declare dependencies on host adapters such as `IGameDispatcher`, `IStorage`, `ISceneRoot`, and `IUiHost`, or share mod contracts such as `IGameMod`. See the [Game guide](../game/index.md) for runtime composition.
