# Core contracts {#overview}

`GeWuYou.GFramework.Core.Abstractions` provides contracts such as `IInitializable`, `IEventBus`, `IResourceLoader<T>`, and read-only state interfaces. Reference it directly to define lifecycle participants or implement adapters in a shared library. See the [Core guide](../core/index.md) for default implementations.
