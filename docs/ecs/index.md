# Arch ECS {#overview}

Install `GeWuYou.GFramework.Ecs.Arch` and choose between creating a World and its systems directly or composing the runtime with standard DI. Drive initialization, updates, and shutdown through `IArchRuntime`. A project that shares contracts can reference `GeWuYou.GFramework.Ecs.Arch.Abstractions`.

Start by [running the Arch ECS example](../ecs/arch.md).
