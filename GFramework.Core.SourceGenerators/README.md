# Core.SourceGenerators

[简体中文](#简体中文) · [English](#english)

## 简体中文

为枚举生成扩展方法，为 partial 类型生成优先级。将包加入声明这些类型的消费项目，并使用随包提供的特性。

`GFramework.Core.SourceGenerators` 是编译期包，包含 `GFramework.Core.SourceGenerators.Abstractions` 提供的特性。`[Priority]` 生成的代码使用 `GFramework.Core.Abstractions` 中的 `IPrioritized`，可通过 `GFramework.Core` 或直接引用契约包取得。

[查看使用说明](https://gewuyou.github.io/GFramework/zh-CN/source-generators/)

## English

Generate enum extensions and priority properties for partial types. Install this package in the project that declares those types and apply the supplied attributes.

`GFramework.Core.SourceGenerators` is a build-time package that includes the attributes from `GFramework.Core.SourceGenerators.Abstractions`. Code generated by `[Priority]` uses `IPrioritized` from `GFramework.Core.Abstractions`. Reference those contracts directly or through `GFramework.Core`.

[Read the guide](https://gewuyou.github.io/GFramework/source-generators/)

## 安装 · Install

```bash
dotnet add package GeWuYou.GFramework.Core.SourceGenerators
```
