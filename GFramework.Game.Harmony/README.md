# Game.Harmony

[简体中文](#简体中文) · [English](#english)

## 简体中文

为批准运行的桌面代码模组提供 Harmony 方法补丁。宿主在模组会话配置 HarmonyModExtension，按模组管理应用与撤销。

[查看使用说明](https://gewuyou.github.io/GFramework/zh-CN/game/code-mods.html)

## English

Add Harmony method patches for approved desktop code mods. Configure HarmonyModExtension in the host session and apply and remove patches by mod owner.

[Read the guide](https://gewuyou.github.io/GFramework/game/code-mods.html)

## 安装 · Install

```bash
dotnet add package GeWuYou.GFramework.Game.Harmony
```
