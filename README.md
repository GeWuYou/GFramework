## 简体中文

GFramework 是面向 C# 游戏开发的模块化框架。按项目需要组合应用生命周期、CQRS、配置、场景与 UI、存档以及 Godot 集成。

[入门](https://gewuyou.github.io/GFramework/zh-CN/getting-started/) · [指南](https://gewuyou.github.io/GFramework/zh-CN/guides/) · [示例](https://gewuyou.github.io/GFramework/zh-CN/tutorials/) · [参考](https://gewuyou.github.io/GFramework/zh-CN/api-reference/)

用 Core 开始一个 C# 项目，或从 [Godot 接入教程](https://gewuyou.github.io/GFramework/zh-CN/tutorials/godot-integration.html)运行第一个原生示例。查看[安装与选包](https://gewuyou.github.io/GFramework/zh-CN/getting-started/installation.html)以了解依赖和环境要求。

## English

GFramework is a modular C# framework for games. Add application lifecycle, CQRS, configuration, scenes and UI, saves, or Godot integration as your project needs them.

[Get started](https://gewuyou.github.io/GFramework/getting-started/) · [Guides](https://gewuyou.github.io/GFramework/guides/) · [Examples](https://gewuyou.github.io/GFramework/tutorials/) · [Reference](https://gewuyou.github.io/GFramework/api-reference/)

Start a C# project with Core or run your first native example in the [Godot integration tutorial](https://gewuyou.github.io/GFramework/tutorials/godot-integration.html). See [installation](https://gewuyou.github.io/GFramework/getting-started/installation.html) for dependencies and environment requirements.

```bash
dotnet add package GeWuYou.GFramework.Core
```
