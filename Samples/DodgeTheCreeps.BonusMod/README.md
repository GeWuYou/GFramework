# Bonus Score Mod

[简体中文](#简体中文) · [English](#english)

## 简体中文

通过公开模组 API 给每次得分加一分，并记录当前局内的奖励次数。构建后在内容管理界面启用 Bonus Score、确认代码执行并重启。

[查看教程](https://gewuyou.github.io/GFramework/zh-CN/game/code-mods.html)

## English

Add one point per score increment through the public mod API, tracking awards for the current run. Build the package, enable Bonus Score in the content manager, approve code execution, and restart.

[Read the walkthrough](https://gewuyou.github.io/GFramework/game/code-mods.html)

## 运行 · Run

python3 scripts/build-dodge-mods.py
