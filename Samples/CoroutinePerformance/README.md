# Coroutine Performance

## 简体中文

运行 Core 协程调度测量。标准输出为 JSON，包含运行时、系统和每项测量。比较时使用相同机器、构建和负载。

Measure Core coroutine scheduling. The JSON output includes the runtime, system, and each measurement. Use the same machine, build, and workload when comparing results.
