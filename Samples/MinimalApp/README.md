# MinimalApp

[简体中文](#简体中文) · [English](#english)

## 简体中文

运行普通依赖注入，再用 Architecture 启动并停止订单服务。输出包含问候日志和两个订单处理记录。

[查看教程](https://gewuyou.github.io/GFramework/zh-CN/getting-started/quick-start.html)

## English

Run standard dependency injection and then start and stop an order service with Architecture. The output includes a greeting and two processed orders.

[Read the walkthrough](https://gewuyou.github.io/GFramework/getting-started/quick-start.html)

## 运行 · Run

```bash
dotnet run --project Samples/MinimalApp -c Release
```
