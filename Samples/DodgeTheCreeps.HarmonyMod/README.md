# Double Score Mod

[简体中文](#简体中文) · [English](#english)

## 简体中文

通过 Harmony 宿主扩展将得分翻倍。构建后启用 Double Score (Harmony)、确认代码执行并重启。游戏在退出时撤销补丁。更新游戏后检查补丁目标仍然存在。

[查看教程](https://gewuyou.github.io/GFramework/zh-CN/game/code-mods.html)

## English

Double scoring through the host's Harmony extension. Build the package, enable Double Score (Harmony), approve code execution, and restart. The game removes the patch at shutdown. Verify the patch target after game updates.

[Read the walkthrough](https://gewuyou.github.io/GFramework/game/code-mods.html)
