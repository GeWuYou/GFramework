# Godot.SourceGenerators

[简体中文](#简体中文) · [English](#english)

## 简体中文

为 Godot 消费项目生成项目信息、节点查找、信号绑定、场景辅助与集合注册。添加包后按任务选择特性或 project.godot 输入。

`GFramework.Godot.SourceGenerators` 是单独安装的编译期包，已包含 `GFramework.Godot.SourceGenerators.Abstractions` 提供的特性。场景辅助和其他使用框架运行时类型的生成结果可与 `GFramework.Godot` 配合使用。

[查看使用说明](https://gewuyou.github.io/GFramework/zh-CN/source-generators/)

## English

Generate Godot project metadata, node lookups, signal bindings, scene helpers, and collection registration. Add the package and select attributes or project.godot inputs for the task.

`GFramework.Godot.SourceGenerators` is installed separately at build time and includes the attributes from `GFramework.Godot.SourceGenerators.Abstractions`. Use `GFramework.Godot` alongside it for generated scene helpers and other output that uses framework runtime types.

[Read the guide](https://gewuyou.github.io/GFramework/source-generators/)

## 安装 · Install

```bash
dotnet add package GeWuYou.GFramework.Godot.SourceGenerators
```
