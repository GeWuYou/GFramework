# Game storage

## 简体中文

用 `FileStorage` 将业务键映射到文件，用 `ScopedStorage` 为共享存储分配前缀。读写示例与所有权说明见[文件存储指南](https://gewuyou.github.io/GFramework/zh-CN/game/storage.html)。

## English

Use `FileStorage` to map application keys to files and `ScopedStorage` to assign prefixes within a shared store. See the [file storage guide](https://gewuyou.github.io/GFramework/game/storage.html) for a read/write example and ownership rules.
