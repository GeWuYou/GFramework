# Cqrs.Abstractions

[简体中文](#简体中文) · [English](#english)

## 简体中文

在共享项目中定义 CQRS 消息、处理器与管道契约。使用 Cqrs 提供分发运行时，按需使用 Cqrs.SourceGenerators 生成注册表。

[查看使用说明](https://gewuyou.github.io/GFramework/zh-CN/core/cqrs.html)

## English

Define CQRS messages, handlers, and pipeline contracts in a shared project. Use Cqrs for dispatch and add Cqrs.SourceGenerators when you need a generated registry.

[Read the guide](https://gewuyou.github.io/GFramework/core/cqrs.html)

## 安装 · Install

```bash
dotnet add package GeWuYou.GFramework.Cqrs.Abstractions
```
