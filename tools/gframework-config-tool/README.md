# GFramework Config Tool

[简体中文](#简体中文) · [English](#english)

## 简体中文

在 VS Code 中浏览、编辑和校验 GFramework 的 YAML 游戏配置。安装扩展后打开同时包含 `config/` 和 `schemas/` 的项目根目录，从配置树浏览记录和 JSON Schema。使用表单编辑支持的字段，或直接打开 YAML。批量编辑用于同配置域的顶层标量或标量数组字段。

[在 Marketplace 安装](https://marketplace.visualstudio.com/items?itemName=GeWuYou.gframework-config-tool) · [配置工具指南](https://gewuyou.github.io/GFramework/zh-CN/game/config-tool.html)

## English

Browse, edit, and validate GFramework YAML game configuration in VS Code. Install the extension and open the project root containing `config/` and `schemas/`. Browse records and JSON Schema from the configuration tree. Edit supported fields through the form or open YAML directly. Batch editing applies to top-level scalars or scalar arrays in a single domain.

[Install from the Marketplace](https://marketplace.visualstudio.com/items?itemName=GeWuYou.gframework-config-tool) · [Configuration tool guide](https://gewuyou.github.io/GFramework/game/config-tool.html)
